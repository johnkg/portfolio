# portfolio

Portfolio site for Joseph Ko Gaw, live at https://johnkg.github.io/portfolio/. Astro, plain CSS, no client JavaScript.

- Edit projects in `src/data/projects.ts` (links, descriptions, live URLs).
- `npm install && npm run dev` to preview, `npm run build` to build.
- Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`.
